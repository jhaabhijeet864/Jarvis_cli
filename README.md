# Voice Bot

A Python-based voice assistant that can be controlled by voice commands to perform various tasks on a desktop computer. It can launch applications, control a web browser, search for information on Google and YouTube, and control media playback. The project is designed to be modular and extensible, with separate components for speech-to-text, text-to-speech, command parsing, and action execution.
